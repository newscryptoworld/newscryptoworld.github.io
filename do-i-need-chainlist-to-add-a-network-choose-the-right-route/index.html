Do I need Chainlist to add a network? Choose the right route

Do I need Chainlist to add a network? No: try your wallet’s network list or a dApp prompt first, and verify the chain ID if you add it yourself.

Crypto Record EditorialNov 17, 2026 · 04:11 UTC4 min read

No, you do not need Chainlist to add a network to your wallet.

Your wallet can use a network once it has the network’s details: a Chain ID, an RPC endpoint, a native currency symbol and, optionally, a block explorer address. Chainlist is a directory of EVM networks and these details; it fills the same fields you could enter yourself.

Which route should you use to add a network?

Use the simplest route your wallet or the app provides. Each route asks your wallet to add network details, and every route is free and takes under a minute.

  • Wallet built-in list: If the network is already listed, turn it on in the wallet’s network menu. Popular networks may be available there with one toggle.
  • dApp add prompt: When you connect to an app that needs another network, it may ask your wallet to add it. Approve the wallet popup if you intended to use that app and network.
  • Chainlist: Use it when the network is not built in and the app does not offer a prompt. Search for the network, connect your wallet, choose add, then approve the wallet popup.
  • Manual entry: Type the details into your wallet when you prefer control or have an official source for them. A typo in the RPC endpoint or Chain ID can make the add fail or point the wallet somewhere unexpected.

Chainlist’s role is to provide network details in a directory that can request an add through your wallet. For background on how that directory fits into adding networks, see chainlist.cc.

What should you verify before approving?

The Chain ID is the key value to verify against a trusted source, such as the network’s official documentation. Wallets check whether the RPC endpoint reports the same Chain ID you entered; if the values do not match, the wallet can reject the network. This check helps catch a mismatch, but it does not make an untrusted source safe.

The RPC endpoint is the address your wallet uses to communicate with the network. The native currency symbol labels the currency used for network fees, while the block explorer is an optional address for viewing on-chain activity. Confirm the Chain ID first, then make sure the other values came from a source you trust.

A wallet adding a network is different from a dApp connecting to your wallet. You can see the difference in the prompts: adding registers network details, while connecting lets an app request wallet access. Mixing them up can leave you thinking a network was added when you only connected to an app, or vice versa.

dApps and network directories can request an add using wallet_addEthereumChain, the method defined in EIP-3085. Your wallet shows the request and asks you to approve it; the request does not itself add gas or charge a fee.

What should you do next?

If the wallet lists the network, toggle it on. If the app you meant to use prompts you to add it, approve that popup. Otherwise, use Chainlist or enter details manually from official documentation. The deciding check is whether the Chain ID matches a trusted source; that is what helps you choose a route without guessing at the network details.

Is it safe to connect my wallet to Chainlist?

Connecting shares a wallet connection with the site; it does not by itself mean you have approved a network add. Read the wallet’s request and confirm the network details before approving.

How do I remove a network I added by mistake?

Remove it through your wallet’s network settings. The exact controls depend on the wallet, so check its own instructions if you cannot find the option.

Why does my wallet say the Chain ID doesn’t match?

The RPC endpoint is reporting a different Chain ID from the one entered. Recheck both values against a trusted source before trying again.
