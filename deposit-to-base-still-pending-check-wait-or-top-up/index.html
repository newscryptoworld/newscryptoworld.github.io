Deposit to Base Still Pending? Check, Wait or Top Up

A deposit to Base still pending usually needs time only after Ethereum confirms it; speed up an unconfirmed transaction, or add separate funds if urgent.

Crypto Record EditorialNov 27, 2026 · 22:37 UTC3 min read

A pending deposit to Base should usually be waited out once its Ethereum transaction is confirmed; if it is still unconfirmed, speed it up. Start with the transaction hash on Etherscan, then wait or fund Base separately if you need ETH now, and watch your address on Basescan until the balance appears.

Should you wait or fund Base another way?

Wait when Etherscan shows the Ethereum transaction succeeded; speed it up when Etherscan still shows it pending. A confirmed native deposit cannot be cancelled, so sending another deposit does not replace the first one.

  1. Look up the transaction hash on Etherscan. Open the transaction and read its status. “Pending” means Ethereum has not confirmed it; “Success” means the transaction was included on Ethereum.
  2. Speed it up if it is still unconfirmed. In MetaMask, open the pending transaction and choose “Speed up.” The replacement uses the same nonce with a higher fee, so it competes to be included in place of the original transaction.

    Note: Use the wallet that sent the deposit. A speed-up is for the same transaction, not a second transfer to Base.

  3. Wait if it succeeded, or add separate funds if you need ETH now. A confirmed deposit is normally credited on Base within minutes. If you cannot wait, use an exchange withdrawal to your Base address or Across Protocol to move supported assets from Ethereum to Base. Make sure the route and network you select send funds to Base.

    A native Base bridge deposit starts on Ethereum and reaches Base through the rollup’s deposit contract. The Base bridge transfer is recorded on Ethereum first; Base nodes derive that L1 deposit into the L2 chain.

    The OP Stack sequencing window is the period in which Base gathers the data needed to derive its L2 blocks from Ethereum. A deposit is part of the L1 inputs for its block. If the sequencer’s batch is missing when the sequencing window elapses, the derivation rules allow a deposit-only block, so the confirmed deposit can still be included even when normal sequencing stalls. Think of the window as a deadline for assembling the block’s inputs: the sequencer can delay the arrival, but it cannot remove a confirmed deposit from those inputs. That is why a confirmed deposit is a delay, not a lost transfer.

    If you fund Base through another route while waiting, that is a separate transfer. The original deposit still lands too, so your Base balance may increase twice. Use that option only when you need usable ETH before the pending deposit arrives.

  4. Watch your address on Basescan. Look for the incoming transaction and the updated ETH balance on Base. The balance appearing is the sign the funds are usable on that address.

Working tip: keep the original transaction hash and check both its Etherscan status and the destination address on Basescan. That helps prevent treating an Ethereum confirmation as a Base arrival, or accidentally sending a duplicate deposit.

What to do next

How do I speed up a stuck Ethereum transaction in MetaMask?

Open the pending transaction in MetaMask and select “Speed up.” MetaMask submits a replacement with the same nonce and a higher fee; once Ethereum confirms it, check the transaction status on Etherscan again.

What if my deposit shows on Basescan but not in my wallet?

Compare the recipient address on Basescan with the address selected in your wallet. If they match, switch the wallet to Base and check that address’s ETH balance; the transaction may have arrived while the wallet was showing another network or account.
