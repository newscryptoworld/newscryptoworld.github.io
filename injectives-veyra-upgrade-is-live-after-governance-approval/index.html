Injective’s Veyra upgrade is live after governance approval

Injective’s Veyra upgrade is live on v1.21.0 after a token-weighted vote, adding cross-chain transfers and trading tools through a coordinated validator software change.

Crypto Record EditorialNov 25, 2026 · 17:59 UTC3 min read

Injective’s Veyra upgrade is live on version 1.21.0, following a governance vote that approved the network’s software change. Injective’s upgrade tracker lists the new version as running on mainnet. The change introduces infrastructure for cross-chain transfers and trading tools; it does not itself issue new assets or launch the planned CypherOS privacy platform.

The approval came through proposal 717, which put the upgrade to INJ stakers. As The Defiant reported from the on-chain vote record, voting closed on Nov. 16 with 99.51% support among non-abstaining voting power. About 24.06 million INJ of voting power participated, and turnout reached 42.69%, above the 33.4% quorum.

How the vote moved the network to new software

Injective governance votes are weighted by staked tokens, rather than counting each participant equally. Once the proposal passed, it authorized a coordinated change at block height 193,145,000: the chain would halt at that point, and validators would restart it using the new application software, v1.21.0. The proposal targeted Nov. 24 for reaching that height, rather than naming a fixed time of day.

The release process has two main moving parts. Injective publishes the software binaries; validators install and run them so their nodes can agree on the chain’s state and continue producing blocks. The Injective Foundation’s v1.21.0 release notes identify the mainnet binaries for both injectived and peggo. The upgrade tracker now lists v1.21.0 as live on Injective’s mainnet.

What Veyra adds

The approved package adds Inter-Blockchain Communication, or IBC, capabilities for moving assets between Injective’s Ethereum Virtual Machine environment and connected chains. The EVM is the part of Injective that runs Ethereum-compatible contracts. In practical terms, IBC gives applications a route for transferring assets across those networks; it is connective infrastructure, like adding a transfer lane between two financial systems.

Veyra also adds request-for-quote infrastructure, which lets a trader solicit prices for a transaction, alongside expanded atomic-swap functionality. An atomic swap either completes its linked exchange or reverts it, so one side is not left settled without the other. Together, these tools extend Injective’s existing trading infrastructure and open additional ways for applications to connect assets and request trades.

Privacy remains a separate step

Veyra should not be read as the launch of CypherOS. The proposal describes that native privacy platform as upcoming, while the approved upgrade focuses on trading and connectivity infrastructure. The vote settled the software change; the live release makes that infrastructure available on the network. What it does not establish is how much activity builders or traders will put through the new tools.
