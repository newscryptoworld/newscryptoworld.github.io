Withdraw Proceeds From a Running TWAMM Order

seo_title: Withdraw TWAMM Proceeds Through Etherscan Write Contract

Crypto Record EditorialNov 26, 2026 · 03:14 UTC3 min read

seo_title: Withdraw TWAMM Proceeds Through Etherscan Write Contract

dek: To withdraw TWAMM order proceeds through Etherscan Write Contract, open the pair contract, connect the placing wallet, and submit its order ID to receive bought tokens.

Fraxswap TWAMM proceeds remain in the pair contract until the order owner withdraws them. To get them through Etherscan’s Write Contract tab, connect the placing address and call withdrawProceedsFromLongTermSwap(orderId) on that pair; the bought tokens go to that wallet.

The function belongs to the pair contract, not the Router, so open the pair address on the explorer for the order’s chain. The Fraxswap background explains the AMM and its embedded time-weighted market maker; for this withdrawal, the key detail is that the pair contract holds the order’s proceeds.

The pair address and order ID identify the withdrawal

The pair address tells the explorer which contract holds the order, and the order ID selects which proceeds to withdraw. You need the placing wallet, order ID, pair address, and that chain’s gas token before submitting a transaction.

Use the explorer that matches the network where you placed the order: Etherscan, Fraxscan, or Arbiscan. The pair address is the destination for this contract call; the Router is not where you withdraw proceeds.

Withdraw and verify the proceeds in five steps

Use the pair’s Read Contract tab to inspect the order, then its Write Contract tab to submit the withdrawal.

  1. Open the transaction that placed the long-term order. Record the pair contract address and the order ID associated with that order, then open the pair address on its chain’s explorer.

  2. Choose Read Contract and call getTwammOrder with the order ID. Confirm that the order owner is the address you will connect and note the expiry.

    A withdrawal can happen before expiry. It pays out proceeds bought so far, while the long-term order continues to run.

  3. Choose Write Contract and connect to Web3 with the wallet that placed the order. Make sure the wallet is on the same network as the pair contract.

    The owner check matters: only the address that placed the order can withdraw its proceeds. Keep the chain’s gas token available to submit the transaction.

  4. Find withdrawProceedsFromLongTermSwap, enter the order ID, and submit the transaction. The function takes a uint256 orderId, so use the order ID itself as the input.

  5. After the transaction succeeds, open its ERC-20 token transfers. A transfer of the bought tokens to your address confirms the withdrawal; the tokens should also appear in the connected wallet.

Related

Why does my TWAMM withdraw transaction revert?

A common cause is connecting an address other than the one that placed the order. Recheck the owner returned by getTwammOrder, the order ID, and that the wallet is connected to the pair’s network.

What if the Write Contract tab is missing?

Confirm that you opened the pair contract address on the correct chain’s explorer. The withdrawal function is on the pair contract, so opening the Router or another address will not show the right call.
